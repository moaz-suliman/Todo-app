#  Todo App

A clean and modern task management application built with **Flutter**, integrating **FreeAPI** for user authentication and robust local state management.

---

## Features

- **User Authentication:** Secure login and registration capabilities integrated with FreeAPI endpoints.
- **Task Management:** Add, delete, and organize daily tasks efficiently with a responsive UI.
- **State Management:** Clean state handling using **Provider**.
- **Secure Storage:** Persistent token management via **Flutter Secure Storage**.
- **Architecture:** Structured following the **MVVM** pattern.

---

## Technologies Used

- **Flutter & Dart** – Cross-platform mobile development
- **Provider** – State management
- **GetIt** – Dependency injection
- **Flutter Secure Storage** – Secure local token storage
- **FreeAPI** – Remote authentication and user endpoints
- **REST API** – Remote data communication

---

## Architecture

The application strictly adheres to the **MVVM (Model-View-ViewModel)** architectural pattern to separate UI components from business logic and data layer operations.
